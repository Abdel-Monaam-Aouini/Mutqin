# Mutqin (متقن)

On-device Quran recitation checker. The user recites, the engine listens and flags mistakes,
helping them reach itqan (precise mastery). Monorepo: shared C++ core, a CLI to test it, Python
tools, and (later) Android and iOS apps.

**Current scope:** C++17 core `MutqinCore` + `mutqin-cli`. `android/` and `ios/` are placeholders.

## Working with an AI coding assistant

1. `AGENTS.md` holds the rules (Cursor, Codex, and others read it). `CLAUDE.md` is the entry
   point for Claude Code, with rules in `.claude/rules/` and skills in `.claude/skills/`.
2. Use `START_PROMPT.md` to begin a session; then say "next" for each task.
3. Work one task at a time from `docs/TASKS.md`.

## Checks before a commit

```
python3 -m venv .venv   # or: uv venv .venv
.venv/bin/pip install -r tools/requirements-dev.txt       # pytest, ruff, clang-format (pinned)
.venv/bin/ruff format tools && .venv/bin/ruff check tools
git ls-files '*.h' '*.cpp' | xargs .venv/bin/clang-format -i
cmake -S . -B build -DMUTQIN_WERROR=ON && cmake --build build && ctest --test-dir build --output-on-failure
.venv/bin/python -I -m pytest -q
```

CI (`.github/workflows/ci.yml`) runs the same on every push and pull request: format and lint,
Python tests, and build + test on Linux (gcc, clang, AddressSanitizer + UBSan), macOS and Windows.

**Quran text in CI.** `data/quran/*.txt` is not in the repository. The jobs download it from Tanzil only
if you set the repository Actions variable `TANZIL_TERMS_ACCEPTED=true` (Settings, Secrets and
variables, Actions, Variables), which records that you accept the
[Tanzil Terms of Use](https://tanzil.net/docs/Text_License). The download must match the committed
`data/quran/checksums.txt` or the job fails. Without the variable the tests that need the text are skipped
and the run shows a warning.

## Important

- Quran text always comes from a verified source file (Tanzil), never typed or generated by AI.
- The tajweed spec must be reviewed by a qualified teacher (with ijazah) before release.
- Verify licenses of every dataset, font, and model before commercial use.
