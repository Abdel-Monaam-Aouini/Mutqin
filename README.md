# Mutqin (متقن)

On-device Quran recitation checker. The user recites, the engine listens and flags mistakes,
helping them reach itqan (precise mastery). Monorepo: shared C++ core, a CLI to test it, Python
tools, and (later) Android and iOS apps.

**Current scope:** C++17 core `MutqinCore` + `mutqin-cli`. `android/` and `ios/` are placeholders.

## Working with an AI coding assistant

1. `AGENTS.md` holds the rules (Cursor, Codex, and others read it). `CLAUDE.md` is the entry
   point for Claude Code, with rules in `.claude/rules/` and skills in `.claude/skills/`.
2. Use `START_PROMPT.md` to begin a session; then say "next" for each task.
3. Work one task at a time from `docs/TASKS.md`.

## Files

| File | Purpose |
|------|---------|
| `AGENTS.md` | Rules and context the AI must always follow |
| `CLAUDE.md` | Claude Code entry point |
| `docs/PLAN.md` | Phased roadmap with acceptance criteria |
| `docs/ARCHITECTURE.md` | Components, folder layout, C API (`mq_`) |

| `docs/DATA_AND_MODEL.md` | Datasets, model training, evaluation |
| `docs/TASKS.md` | Task checklist, phase by phase |

## Important

- Quran text always comes from a verified source file (Tanzil), never typed or generated by AI.
- The tajweed spec must be reviewed by a qualified teacher (with ijazah) before release.
- Verify licenses of every dataset, font, and model before commercial use.
